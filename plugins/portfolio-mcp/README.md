# harshith-portfolio

A Claude Code plugin with no files of its own: its marketplace entry in
`.claude-plugin/marketplace.json` declares the site's two read-only MCP
servers, `/mcp` (portfolio content) and `/mcp/docs` (developer docs). This
directory exists so the plugin has a root that holds nothing else.

```
/plugin marketplace add HarshithNayakaL/My-Portfolio
/plugin install harshith-portfolio@harshith-nayaka-l
```
